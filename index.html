Deployment modes

Same scoring API, different routing.

Customers can stay fully local, point at a private server, or adopt a hosted endpoint later without rewriting their training or inference loops.

Mode 1

Local artifact

Load `./integrity.json` and score in-process. Best for notebooks, air-gapped experiments, and teams that want zero service footprint.

Mode 2

Hosted cloud

Point the SDK at a hosted endpoint and keep centralized artifacts, status, and scoring history while still extracting features locally.

Mode 3

Self-hosted

Run `signai-server` inside a VPC or on a single node with file or SQLite storage. The SDK behavior stays the same.

Mode 4

Air-gapped

Use the same remote contract against a private internal host with no internet connectivity and no model weight transfer.

How to run

Start local, then graduate to server mode.

The production layer is built around a very small operational loop: calibrate, save, load, score, and optionally upload the artifact to a service.

SDK quickstart

  • Attach a monitor with `monitor.attach(...)`.
  • Calibrate on clean data with `phase="inference"` or `phase="training"`.
  • Save to `integrity.json`.
  • Reload locally or point at `signai-server`.
  • Call `score_inference(x, y)` or `score_training(logits, loss)` in hot paths.
from signai import monitor

m = monitor.attach(model, num_classes=10, device="cuda")
m.calibrate(clean_loader, device="cuda", phase="inference", calib_batches=200)
m.save("./integrity.json")

m = monitor.load(model, artifact="./integrity.json", device="cuda")
result = m.score_inference(x, y)

Server quickstart

  • `signai-server serve` starts the standalone production API.
  • `signai serve` is a convenience shortcut.
  • Community uses file storage.
  • Pro adds history, notifier, audit export, and status.
  • Enterprise adds Postgres-oriented deployment.
pip install "signai[server]"
signai-server serve \
  --host 0.0.0.0 \
  --port 8000 \
  --storage ./artifacts \
  --store-backend file \
  --edition community

docker compose up --build
